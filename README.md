# 🛡️ CyberSentinel

CyberSentinel is a cybersecurity awareness web application built using HTML, CSS, and JavaScript.

---

## 🚀 Features
- URL Risk Scanner (detects suspicious links)
- Password Strength Analyzer
- Cyber Safety Score System
- Cyber Awareness Page

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

---

## 📚 What I learned
- Web development fundamentals
- JavaScript logic building
- Basic cybersecurity concepts (phishing, password safety)
- Multi-page website structure
